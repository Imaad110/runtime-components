# Runtime Components

My collection of personal configuration files and setup scripts to keep my development environment consistent across machines.

## Included Files
- **.bashrc**: Configuration for Bash shells
- **.zshrc**: Configuration for Zsh shells
- **.vimrc**: Vim editor settings and preferences
- **.gdbinit**: GDB debugger preferences
- **.gitconfig**: Git configurations and aliases
- **install.sh**: Automation script to deploy and back up these files to your home directory
